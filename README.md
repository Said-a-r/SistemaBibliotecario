# Sistema de Gestión de Biblioteca

Sistema Bibliotecario que adminstra Usuarios, Libros y Prestamos utilziando C# atendido mediante consola

## Funcionalidades

- Registrar libros.
- Registrar usuarios.
- Listar libros.
- Buscar libros por código, autor o categoría.
- Eliminar libros.
- Ver libros disponibles.
- Registrar préstamos.
- Devolver libros.
- Ver préstamos activos.

## Tecnologías

- C#
- .NET sdk linux y la version 10 en windows

## Ejecución

Los pasos para ejecutar el proyecto serian clonar el proyecto son

En terminal:

```bash
git clone https://github.com/Said-a-r/SistemaBibliotecario.git
```

En la terminal del proyecto, osea en la carpeta ejecutar:

```bash
>dotnet restore
>dotnet run

```

Y ya estaria
